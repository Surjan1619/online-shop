**Online Shop** is a full-featured e-commerce platform built with
**FastAPI**, **SQLAlchemy**, and **asyncpg**.\
It allows users to create, sell, and purchase products through a modern
asynchronous backend architecture.

The project is currently under active development and will include
advanced features such as real-time chat, product analytics, and
enhanced monitoring tools.

------------------------------------------------------------------------

## 🚀 Features

- ✅ Create, edit, and manage products\
- ✅ Browse and purchase products from other users\
- ✅ Admin panel for monitoring products\
- ✅ Category management system\
- ✅ Asynchronous database operations using `asyncpg`\
- ✅ API built with **FastAPI**\
- ✅ Secure authentication using **JWT tokens**\
- ✅ Fully asynchronous CRUD operations

------------------------------------------------------------------------
